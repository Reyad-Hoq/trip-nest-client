# ✈️ TripNest Client

TripNest is a modern ticket booking platform built with **Next.js** where users can search, book, and manage Bus, Train, Flight, and Launch tickets. Vendors can publish tickets, while admins manage users and approve ticket listings.

## 🚀 Live Demo

https://your-client-url.vercel.app

---

## ✨ Features

### 👤 Authentication

- Better Auth Authentication
- Email & Password Login
- Google Sign In
- JWT Authentication
- Role Based Access Control (User, Vendor, Admin)

### 🎫 Ticket System

- Search Tickets
- Filter by
  - From
  - Destination
  - Transport
  - Date
- Pagination
- Ticket Details

### 👥 User Dashboard

- View Profile
- My Bookings
- Payment
- Booking Status

### 🏪 Vendor Dashboard

- Vendor Profile
- Add Ticket
- Edit Ticket
- Delete Ticket
- View Added Tickets
- Booking Requests
- Revenue Dashboard

### 👑 Admin Dashboard

- Manage Users
- Manage Vendors
- Approve / Reject Tickets
- Platform Statistics
